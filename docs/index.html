面向俱乐部运营的产品模块

用户可以浏览和筛选俱乐部、按 ID 或名称申请加入；管理者可以审核成员、查看记录，并配置玩法、时长、座位、盲注和服务费。仓库同时提供 C++/Tars 大厅、房间、GM 与 MySQL 数据访问相关代码，便于技术团队评估二次开发范围。

页面依据仓库源码和实际产品截图整理。公开目录依赖外部 XGame/Tars 环境，不应理解为无需配置即可上线的完整成品。
