俱乐部大厅

发现与筛选

查看在线人数、平均底池和活跃度，筛选空满桌、德州、AOF、6+ Short Deck 与 6/9 人桌。

会员系统

加入与审核

按 ID/名称申请加入，查看成员在线状态，处理会员申请和俱乐部资料。

运营数据

账单与排行

查看日/月账单和保险记录，按等级、财富和活跃度查看排行榜。

玩法入口

德州、AOF 与 6+ Short Deck

筛选面板将玩法、座位数和牌桌状态放在同一层级，用户可以更快找到合适的牌局。这里描述的是截图可见的产品配置，不推断仓库是否包含每种玩法的全部算法。

加入流程

会员管理

成员状态、审核、记录与账单

俱乐部资料页展示会员列表和在线状态，并提供审核、记录和账单入口，方便管理者完成日常运营。
